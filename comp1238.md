## Week 1 - History
- One writing system can be used by many languages.
- Early computing evolved from mechanical calculators to digital systems.
- Cuneiform and ancient record-keeping laid the foundation for structured information.

## Week 2 - Bits and Bytes
- A bit is the smallest unit of data, representing a 0 or a 1.
- A byte consists of 8 bits and can represent 256 distinct values.
- Binary code uses base-2 arithmetic to process all computer instructions.

## Week 3 - Text Structure
- Plain text files contain raw characters without built-in styling or formatting.
- Markdown uses simple symbols like hashes and asterisks to structure readable documents.
- Character encodings like ASCII and UTF-8 translate binary numbers into visible text.

## Week 4 - Keyboards and Editors
- Text editors handle raw text files, unlike word processors which add hidden layout data.
- Keyboard shortcuts significantly increase efficiency when writing and editing code.
- Modal editors like Vim use different states for navigating text versus inserting text.

## Week 5 - CLI
- The Command Line Interface allows users to interact with a computer using text commands.
- Directory navigation relies on commands like `cd` to change folders and `pwd` to print the current path.
- Standard inputs and outputs can be redirected or piped into different commands.
